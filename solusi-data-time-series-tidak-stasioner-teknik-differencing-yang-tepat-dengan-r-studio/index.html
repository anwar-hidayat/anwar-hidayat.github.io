Solusi Data Time Series Tidak Stasioner: Teknik Differencing yang Tepat dengan R-Studio

Model Autoregressive Integrated Moving Average (ARIMA) atau analisis ekonometrika sering kali menghasilkan estimasi palsu (spurious regression) ketika digunakan pada data yang mengalami tren tidak stasioner. Gejala utama masalah ini ditandai dengan nilai R-squared yang sangat tinggi (di atas 0,90) namun nilai Durbin-Watson statistic sangat rendah (di bawah 1,0), atau munculnya peringatan system error dalam R-Studio seperti non-stationary AR part from ARIMA model saat menjalankan pemodelan deret waktu. Jika Anda menghadapi kendala ini, penerapan solusi data time series tidak stasioner melalui pendekatan uji akar unit (unit root test) dan transformasi pembedaan (differencing) menjadi langkah wajib untuk mengembalikan integritas estimasi statistik.

Data deret waktu (time series) di sektor ekonomi, bisnis, maupun meteorologi umumnya memiliki komponen tren, varians yang berubah dari waktu ke waktu, serta rata-rata (mean) yang tidak konstan. Ketika data berfluktuasi tanpa kembali ke titik rata-rata historisnya, asumsi dasar pemodelan statistik klasik langsung terlanggar. Mengabaikan ketidakstasioneran ini akan mengakibatkan estimasi koefisien menjadi tidak konsisten, standard error bias, serta pengujian hipotesis (seperti uji t dan uji F) memberikan kesimpulan yang salah secara ilmiah.

Konsep Dasar Stasioneritas dan Akar Unit

Secara teoretis, suatu proses deret waktu dikatakan stasioner jika sifat-sifat statistiknya, yaitu rata-rata (mean), varians (variance), dan autokovarians (autocovariance), bersifat konstan sepanjang waktu (time-invariant). Gujarati dan Porter (2009) menegaskan bahwa stokastik stasioner merupakan prasyarat mutlak dalam analisis time series agar model yang dibentuk memiliki daya prediksi yang valid dan stabil untuk periode masa depan.

Menurut Box dan Jenkins (1976), sebagian besar data ekonomi dan bisnis dunia nyata dikategorikan sebagai non-stationary processes yang tergolong dalam integrated process ordo d, dinotasikan sebagai I(d). Data yang tidak stasioner pada tingkat level I(0) membutuhkan operasi pembedaan (differencing) sebanyak d kali hingga menjadi stasioner I(d) sebelum dapat dimasukkan ke dalam komponen autoregressive (AR) dan moving average (MA).

Pengujian stasioneritas secara formal dihitung menggunakan pengujian akar unit (unit root test), seperti Augmented Dickey-Fuller (ADF) test atau Phillips-Perron (PP) test. Untuk mempelajari konsep dasar teoretis dan formulasi matematis dari uji Dickey-Fuller dan stasioneritas data, Anda dapat membaca artikel landasan teori lengkap di statistikian.com. Pemahaman dasar ini sangat penting agar pertimbangan matematis di balik pemilihan tingkat pembedaan tidak keliru.

Hamilton (1994) menyatakan bahwa kegagalan mengidentifikasi akar unit pada data deret waktu akan menyebabkan efek kejut (shocks) bersifat permanen (permanent memory), bukan sementara (transitory memory). Oleh sebab itu, transformasi data melalui differencing bertujuan menghapus komponen tren deterministik maupun stokastik dan menyisakan komponen variasi yang bersifat white noise.

Langkah Teknis Perbaikan Data Tidak Stasioner di R-Studio

Untuk menyelesaikan masalah ketidakstasioneran secara sistematis, berikut adalah prosedur kerja praktis menggunakan lingkungan pemrograman R-Studio beserta pustaka pendukung utama seperti tseries dan forecast.

Langkah 1: Persiapan Lingkungan Kerja dan Import Data
Persiapkan pustaka yang dibutuhkan dan buat objek time series dalam R. Pembuatan objek time series dilakukan menggunakan fungsi ts() dengan menentukan frekuensi data yang tepat.

# Memuat pustaka yang diperlukan
library(tseries)
library(forecast)

# Membuat contoh data time series tidak stasioner
set.seed(123)
data_raw <- cumsum(rnorm(100, mean = 0.5, sd = 2)) # Random walk dengan drift
ts_data <- ts(data_raw, start = c(2020, 1), frequency = 12)

# Plot data awal
plot(ts_data, main = "Plot Time Series Data Level I(0)", 
     ylab = "Nilai Observasi", xlab = "Waktu", col = "black", stroke = 2)

Langkah 2: Uji Akar Unit Awal dengan Augmented Dickey-Fuller (ADF) Test
Pengujian formal dilakukan pada tingkat level I(0) menggunakan fungsi adf.test(). Hipotesis nol (H0) menyatakan bahwa data memiliki akar unit (tidak stasioner), sedangkan hipotesis alternatif (H1) menyatakan data stasioner.

# Pelaksanaan Uji ADF pada skala Level
adf_level <- adf.test(ts_data)
print(adf_level)

Alasan ilmiah: Jika nilai p-value > 0,05, maka H0 gagal ditolak. Hal ini membuktikan secara empiris bahwa data awal mengalami ketidakstasioneran dan memerlukan transformasi lanjutan.

Langkah 3: Menentukan Derajat Differencing Secara Otomatis
Sebelum melakukan diferensiasi manual, gunakan fungsi ndiffs() dari pustaka forecast untuk mengestimasi jumlah pembedaan yang diperlukan secara objektif. Enders (2014) menyarankan penggunaan uji otomatis berbasis KPSS atau ADF untuk mengonfirmasi jumlah diferensiasi optimal.

# Menentukan jumlah diferensiasi yang dibutuhkan
d_required <- ndiffs(ts_data, test = "adf")
cat("Jumlah differencing yang direkomendasikan (d):", d_required, "\n")

Langkah 4: Eksekusi Transformasi First Differencing
Transformasi pembedaan tingkat pertama (first differencing, d = 1) dilakukan dengan menghitung selisih antara observasi pada periode t dengan periode sebelumnya (t - 1). Di R-Studio, gunakan fungsi diff().

# Melakukan First Differencing (d = 1)
ts_diff1 <- diff(ts_data, differences = 1)

# Plot data hasil differencing
plot(ts_diff1, main = "Plot Data Setelah First Differencing I(1)", 
     ylab = "Nilai Selisih (Delta)", xlab = "Waktu", col = "#002B49")
abline(h = 0, col = "red", lty = 2)

Langkah 5: Evaluasi Ulang Stasioneritas Hasil Differencing
Lakukan uji ADF kembali pada variabel ts_diff1 untuk memastikan bahwa komponen akar unit telah berhasil dihilangkan.

# Uji ADF pada data hasil First Differencing
adf_diff1 <- adf.test(ts_diff1)
print(adf_diff1)

Alasan ilmiah: Apabila nilai p-value < 0,05, H0 ditolak. Ini menunjukkan bahwa data telah menjadi stasioner pada tingkat ordo integrasi pertama I(1) dan siap digunakan untuk pemodelan ARIMA.

Langkah 6: Pemeriksaan Plot Autocorrelation (ACF) dan Partial Autocorrelation (PACF)
Evaluasi struktur autokorelasi pada data stasioner untuk mengidentifikasi calon nilai ordo p (AR) dan q (MA) menggunakan fungsi acf() dan pacf().

# Menampilkan plot ACF dan PACF side-by-side
par(mfrow = c(1, 2))
acf(ts_diff1, main = "ACF Data Stasioner")
pacf(ts_diff1, main = "PACF Data Stasioner")
par(mfrow = c(1, 1))

Langkah 7: Estimasi Model ARIMA Berbasis Data Stasioner
Gunakan fungsi auto.arima() dengan menetapkan parameter diferensiasi sesuai hasil analisis sebelumnya untuk mendapatkan model optimal berdasarkan kriteria Information Criterion (AIC/BIC).

# Estimasi model ARIMA optimal
fit_arima <- auto.arima(ts_data, d = d_required, seasonal = FALSE, stepwise = FALSE)
summary(fit_arima)

Langkah 8: Diagnostik Residual Model
Langkah terakhir adalah memastikan residual dari model yang dibentuk telah terbebas dari autokorelasi dan berperilaku sebagai white noise menggunakan uji Ljung-Box via fungsi checkresiduals() atau Box.test().

# Uji diagnostik residual Ljung-Box
checkresiduals(fit_arima)

Pembahasan Ilmiah: Implikasi Metodologis dan Risiko Pemodelan

Penentuan derajat differencing yang tepat menuntut kecermatan tinggi dari peneliti. Tsay (2010) memperingatkan bahaya over-differencing, yaitu kondisi ketika operasi pembedaan dilakukan secara berlebihan pada data yang sebenarnya telah mencapai stasioneritas pada tingkat ordo yang lebih rendah.

Over-differencing dapat menginduksi struktur Moving Average (MA) buatan pada deret waktu, meningkatkan varians sampel, serta menghilangkan informasi hubungan jangka panjang (long-run equilibrium) yang sangat berharga dalam analisis ekonometrika. Kondisi ini membuat parameter model menjadi redundan dan mengurangi akurasi ramalan.

Sebaliknya, kondisi under-differencing membiarkan komponen akar unit tetap berada di dalam sistem pemodelan. Akibatnya, fenomena spurious regression dan masalah varians tak berhingga (infinite variance) tetap berlangsung. Hyndman dan Athanasopoulos (2021) menekankan bahwa kombinasi uji statistik formal (seperti kombinasi ADF test dan KPSS test) bersama pemeriksaan visual plot ACF/PACF merupakan strategi terbaik untuk menghindari kesalahan komputasi tersebut.

Uji Kwiatkowski-Phillips-Schmidt-Shin (KPSS) sering digunakan sebagai konfirmasi silang terhadap uji ADF. Berbeda dengan uji ADF yang hipotesis nolnya menyatakan data tidak stasioner, uji KPSS memiliki hipotesis nol bahwa data bersifat stasioner (trend stationary). Penggunaan kedua uji ini secara bersamaan membantu mengonfirmasi status stasioneritas data secara lebih robust (Kwiatkowski et al., 1992).

Apabila data memiliki pola musiman (seasonal pattern), teknik differencing biasa perlu dikombinasikan dengan pembedaan musiman (seasonal differencing). Menurut Wooldridge (2013), untuk data bulanan dengan periode S = 12, pembedaan musiman dilakukan dengan menghitung selisih antara nilai observasi pada periode t dengan periode t - 12 (dinotasikan sebagai D = 1).

Selain differencing, penanganan ketidakstasioneran yang disebabkan oleh tren deterministik (trend stationary process) dapat dilakukan melalui teknik detrending, yaitu meregresikan data terhadap variabel tren waktu t. Namun, Nelson dan Plosser (1982) dalam studi monumental mereka menemukan bahwa sebagian besar variabel makroekonomi dan bisnis terbukti tergolong difference stationary process (DSP), sehingga transformasi differencing jauh lebih relevan dibandingkan sekadar detrending linear.

Dalam konteks analisis data multivariat, jika dua atau lebih variabel time series tidak stasioner pada skala level I(0) namun saling memiliki hubungan jangka panjang yang stasioner pada kombinasi linearnya, maka diferensiasi tidak boleh dilakukan secara parsial tanpa melakukan uji kointegrasi (cointegration test). Johansen (1991) menjelaskan bahwa dalam kondisi terkointegrasi, pemodelan Vector Error Correction Model (VECM) menjadi opsi yang jauh lebih tepat dibandingkan membedakan data secara langsung pada model Vector Autoregressive (VAR) standar.

Kesimpulan

Masalah data time series yang tidak stasioner merupakan tantangan umum dalam pemodelan kuantitatif yang jika diabaikan dapat merusak keabsahan analisis statistik. Melalui penerapan teknik differencing yang tepat di R-Studio, komponen tren stokastik dan akar unit dapat dieliminasi sehingga data mencapai kondisi stasioner I(1) atau I(d). Prosedur diagnostik berbasis uji ADF, evaluasi otomatis ordo pembedaan dengan ndiffs(), serta konfirmasi residual white noise memastikan model ARIMA yang dihasilkan terbebas dari regresi palsu (spurious regression) dan memiliki akurasi peramalan yang optimal secara ilmiah.
